# Comparison with Other Addons

Last checked: **2026-11-13**. Waypoint Tracker baseline: **1.4.0**.

[Comparison hub](https://sanjaygbhat.github.io/wowforever-waypoint-tracker/compare.html) · [Waypoint Tracker home](https://sanjaygbhat.github.io/wowforever-waypoint-tracker/)

Waypoint Tracker combines a 3D waypoint arrow with Find for quests, NPCs, enemies, objects and items on WoW Forever. Real routes is a standard feature, on by default: it plans the fastest known usable journey, including flight paths, boats, zeppelins, the tram, hearthstone and usable teleports. The default Safe route preference asks before a quicker route crosses dangerous ground; Always fastest is optional.

Nearest finds known services and class, profession, weapon and riding trainers for your faction. Class Trainer selects your class; Profession Trainer lets you choose a profession. Use /wp, open Find and choose Nearest, or use the minimap button’s right-click Nearest menu.

Waypoint Tracker accepts supported TomTom waypoint calls when TomTom is absent. When TomTom is installed, Waypoint Tracker leaves /way and the waypoint API to it; /wp remains available. A TomTom-compatible destination handoff does not establish that every guide, dependency check or API extension is interchangeable.

Treasure hunt (beta) and Route sharing & votes (beta) are off by default.

## Which should I use?

- **A 3D arrow, NPC/item/quest lookup and nearest trainers:** Use Waypoint Tracker for Find, Nearest and Real routes to a destination you choose.
- **Coordinate waypoints and arrow themes:** TomTom provides that workflow and lists Forever support; compare its arrow controls with Waypoint Tracker’s Find and travel tools.
- **A map overview of quests:** Questie documents quest starts, objectives, turn-ins and journey history. Waypoint Tracker adds selected-destination navigation.
- **A suggested leveling sequence:** Use a guide such as Zygor, RestedXP, Guidelime, WoW-Pro, Polestar or Wayfinder Forever. Check Forever coverage and guide maturity; a travel planner is a different task from choosing quests.
- **Browsable location pins:** Use HandyNotes with the relevant Forever plugin. Rare, treasure, service, transport and book plugins have different datasets.
- **A replacement map workspace:** Consider Carbonite All in One, OpenMap or Endless Map; Mapster and Leatrix Maps offer map adjustments.
- **Gathering, collections or dedicated alerts:** Choose the specialist workflow: GatherMate2 or a Forever gathering tool, ATT for collection tracking, or RareScanner/SilverDragon for rare detection. These roles can complement destination navigation.

## TomTom vs Waypoint Tracker

TomTom supplies coordinate waypoints, map clicks, a floating arrow and corpse guidance. Choose TomTom for its waypoint workflow and arrow themes; choose Waypoint Tracker for a 3D arrow with built-in Find, Nearest and Real routes.

**Can I use both?** Yes. When TomTom is installed, Waypoint Tracker leaves /way and the waypoint API to TomTom. Use /wp for Waypoint Tracker; third-party TomTom waypoints then belong to TomTom.

## Questie vs Waypoint Tracker

Questie shows quest starts, objectives and turn-ins on the map, with a quest tracker and searchable database. Choose Questie for a quest-map overview and journey history; choose Waypoint Tracker for named destinations and a 3D arrow with travel planning.

**Can I use both?** Questie documents TomTom objective arrows, and Waypoint Tracker documents a compatible waypoint API. Using supported TomTom calls with TomTom absent is an expected pairing, not a live-client result from this comparison. If TomTom is installed, it owns that API.

## pfQuest vs Waypoint Tracker

pfQuest combines a quest arrow, objective map nodes and a database browser for NPCs, items, objects and quests on its documented Vanilla/TBC clients. For a documented Forever 1.60.1 build, choose Waypoint Tracker; pfQuest is a relevant database and quest-helper comparison for its own supported clients.

**Can I use both?** A supported Forever build of upstream pfQuest was not verified. Do not assume a Vanilla or TBC addon loads on Forever. Use Waypoint Tracker on Forever; direct integration with pfQuest is not stated.

## HandyNotes vs Waypoint Tracker

HandyNotes is a map-note framework with personal notes and separate plugins for location data. Choose HandyNotes and a suitable plugin for browsable map markers; choose Waypoint Tracker for Find and arrow guidance to a selected destination.

**Can I use both?** A Forever-compatible HandyNotes build and a compatible plugin can supply map notes alongside Waypoint Tracker. Plugins that send supported TomTom waypoint calls can target its arrow when TomTom is absent; the core alone does not establish that integration.

## Questions and answers

**Which WoW Forever addon combines a waypoint arrow with NPC and item search?**

Waypoint Tracker combines a 3D arrow with Find for quests, NPCs, enemies, objects and items. It is free under the MIT licence and targets Forever 1.60.1, interface 16001.

**Does Classic Era support establish WoW Forever compatibility?**

No. Check for an explicit Forever release or official Forever documentation. Upstream pfQuest documents Vanilla/TBC clients; a Forever build was not verified in the checked sources.

**Can TomTom-compatible addons send waypoints to Waypoint Tracker?**

Waypoint Tracker accepts supported TomTom waypoint calls when TomTom is absent. When TomTom is installed, Waypoint Tracker leaves /way and the waypoint API to it; /wp remains available. A TomTom-compatible destination handoff does not establish that every guide, dependency check or API extension is interchangeable.

**How do I find the nearest class or profession trainer in WoW Forever?**

Nearest finds known services and class, profession, weapon and riding trainers for your faction. Class Trainer selects your class; Profession Trainer lets you choose a profession. Use /wp, open Find and choose Nearest, or use the minimap button’s right-click Nearest menu.

**Should I use a leveling guide or Waypoint Tracker?**

Use a leveling guide when you want instructions about which quests to accept, complete and turn in. Use Waypoint Tracker for Find, nearest known services and travel to your chosen destination; direct guide integrations must be checked individually.
